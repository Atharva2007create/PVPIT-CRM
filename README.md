# PVPIT Student CRM

Unified Student CRM for PVPIT Engineering College. This repository currently contains only the Phase 1 backend foundation. It is a non-production MVP and exposes no authentication or business-module APIs yet.

The system has exactly two planned application roles:

- `student`
- `administrator`

Both workflows will use one frontend, one Express API, one authentication system, and one MongoDB database. See [backend/README.md](backend/README.md) for setup and current scope.

No frontend files are included or modified in this phase.
